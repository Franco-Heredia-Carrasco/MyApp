# 📱 PreveeApp

Esta app busca hacer una app que permita la preveecion de desastres naturales dando consejos
mediantes guías y funciones que permitan una mayo facilidad al hacer estas preveenciones.

---

- **Característica 1:** Autenticación local y gestión de usuarios (SQLite).
- **Característica 2:** Control de sesión activa del empleado (SharedPreferences).
- **Característica 3:** Navegación fluida e intuitiva mediante `BottomNavigationView`.
- **Característica 4:** Modificación segura de contraseñas.
- **Característica 5:** Autenticación con Firebase.

---

* **Lenguaje:** Java  
* **Diseño de Interfaz:** Vistas XML (Material Design 3)
* **Arquitectura:** MVC / Estándar Android
* **Conexión a Red:** Offline por ahora (Futura integración Cloud)
* **Base de Datos:** SQLite nativo

---

- **Android Studio:** Versión Jellyfish / Ladybug o superior
- **Versión de Java:** JDK 17+
- **SDK Mínimo:** API 26 (Android 8.0)
- **SDK Objetivo:** API 34 (Android 14)

---

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/Franco-Heredia-Carrasco/MyApp
   ```
2. Abre **Android Studio** y selecciona la opción **Abrir** para cargar el proyecto.
3. Espera a que termine la sincronización inicial de **Gradle** (**Archivo** > **Sincronizar
   proyecto con archivos Gradle**).
4. Conecta un dispositivo físico o inicia un emulador y haz clic en el botón **Ejecutar** (ícono de
   play verde).
